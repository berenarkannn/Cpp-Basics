# Cpp-Basics
This repository contains my small C++ projects and exercises. 
It's a collection of beginner-friendly programs where I practice basic C++ concepts like:

- Variables and Input/Output
- Arrays
- Functions
- Loops and Conditions
- Simple mini projects (ATM simulation, number guessing game, etc.)

The goal is to improve my programming skills and showcase my learning journey. 
All programs are written in a simple and easy-to-understand way.
